# Лабораторная работа №2. Система управления конференциями

## Задание 1.1. Подготовка данных

Использована БД из первой лабораторной работы. Миграция
[003_meeting_statuses.sql](migrations/003_meeting_statuses.sql) добавляет справочник
статусов `meeting_statuses` и поле `meetings.status_code`. Существующим
конференциям назначается статус `planned`.

После миграций `001–003` выполняется [data/generate.sql](data/generate.sql).

- 130 записей в основных таблицах и 3 статуса. В `registrations` — 48 записей,
  в `events` — 24 события.
- 6 конференций завершены (`completed`), 2 запланированы (`planned`),
  1 отменена (`cancelled`).
- Данные за сентябрь, октябрь и ноябрь 2026 года.
- Одни и те же участники регистрируются на разные конференции.
- Есть 4 участника без регистраций, организатор без конференций, неиспользуемые
  комнаты и конференция без событий и участников.
- Есть вместимость 1, оценки 1 и 10, полностью заполненная конференция,
  нулевые количества связанных записей и допустимые `NULL`.

## Задание 1.2. Операции изменения данных

Сценарий [data/dml.sql](data/dml.sql):

1. Создаёт конференцию, событие и регистрацию участника через `INSERT`.
   ID конференции сохраняется через `RETURNING` в переменную `new_meeting_id`
   и используется для связей, изменения статуса и удаления.
2. Меняет статус конференции с `planned` на `cancelled` через `UPDATE`.
3. Увеличивает вместимость запланированных конференций ноября на 10 мест.
4. Удаляет созданную конференцию через `DELETE`. Событие и регистрация удаляются
   каскадно по внешним ключам.
5. Отменяет изменения через `ROLLBACK`.

Запуск после подготовки данных:

```sh
psql -d <имя_базы> -f lab02/data/dml.sql
```

## Задание 2.1. Многотабличные запросы

В [queries/joins.sql](queries/joins.sql) три запроса:

1. Регистрации с данными участника, конференции и организатора — четыре таблицы.
2. Конференции без регистраций с данными организаторов — три таблицы.
   `LEFT JOIN` сохраняет конференции без регистраций, а `WHERE r.member_id IS NULL`
   оставляет только их.
3. События запланированных конференций ноября 2026 года на платформе Zoom — три
   таблицы и условия по статусу, периоду и платформе.

```sh
psql -d <имя_базы> -f lab02/queries/joins.sql
```
